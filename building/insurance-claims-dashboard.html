A data project by Emily Worley

INSURANCE CLAIMS EXPLORER

500,000 policy records SQL / Python / Java / Machine Learning
BEHIND THE ANALYSIS:Overview, data, definitions, and methodology

OVERVIEW

Using SQL and Python, I cleaned auto insurance data, developed features for risk and customer segmentation, and compared six regression models. Random Forest produced the strongest results and was used to generate the predicted claim amounts shown here. I also built a Java pipeline that validates and aggregates the project’s 500,000 synthetic policy records into JSON for the dashboard.


Explore the views below to compare observed and predicted claims, investigate customer segments, and review model performance. Filter by state, coverage, vehicle class, and income band, or select chart categories, to see how patterns change across the portfolio. The risk scores reflect the project’s predefined rules, while predicted claim amounts come from the machine learning model.

THE PORTFOLIO

Charts summarize all 500,000 records in the project’s synthetic claims_predictions.csv export, without sampling. One row is counted as one policy record. Averages are weighted by record count. A Java exporter streams the CSV files into the JSON dataset loaded by this page. This is a static project snapshot.

THE MODEL

Predicted claims come from the exported Random Forest results. The six model benchmarks use the original dataset’s held-out test split (80% training, 20% test; approximately 9,000 source records), rather than the expanded synthetic portfolio. The feature chart shows the ten supplied features without rescaling their importance.

RISK & SEVERITY

Risk scores are the source project’s rules: +2 for income below $30,000, +2 for open complaints, and +3 for claims above $1,500. The score incorporates actual claims and is descriptive. Severity labels follow the source export: low (<$500), medium ($500–$2,000), and high (>$2,000).

READING THE RESULTS

Income bands and severity labels are preserved from the synthetic export. Premium and customer lifetime value can encode existing risk information. Synthetic expansion may limit generalization. No time trend is inferred from the source dates. These are project analysis results, not live underwriting scores.
