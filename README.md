# Personal Website 🪷🐈
Welcome to the repository for my personal website.

🔗 [ekworley.github.io](https://ekworley.github.io)


## Features
* **Dynamic theme toggle** - JavaScript-powered dark/light mode that adapts to user preference and persists across page refreshes via browser storage.
* **Responsive layout** - Optimized design for all screen sizes.
* **Accessibility focused** - Built with modern WAI-ARIA guidelines to ensure the site is fully navigable for screen-reader users.
* **High performance** - Built using lean, vanilla web technologies for instant loading times and clean asset rendering.


## Stack

### Core Architecture
* **HTML5** - Semantic markup, modern document structure, and SEO-friendly tagging.
* **CSS3** - Custom grid/flexbox layouts, responsive design rules, and cohesive typography styling.
* **JavaScript (ES6+)** - Client-side logic handling dynamic theme states, DOM manipulation, persistence, and user interactions.

### Assets & Design
* **[Font Awesome](https://fontawesome.com/)** - Scalable vector icons for clean visual indicators, social networks, and navigation items.
* **[Google Fonts API](https://developers.google.com/fonts)** - Web font embedding optimized for cross-browser custom typography.

### Performance & Accessibility
* **Mobile-first Responsive Design** - Optimized using Viewport Meta tags to ensure adaptive presentation across mobile and desktop screen sizes.
* **[WAI-ARIA](https://www.w3.org/WAI/standards-guidelines/aria/) Standards** - Implemented accessibility attributes to guarantee standard compliance and inclusive design.

### Deployment
* **[GitHub Pages](https://pages.github.com/)** - Automated production hosting and continuous deployment (CI/CD) directly from the repository source code.


## Local Setup
If you want to view, review, or run this project locally on your machine:
1. **Clone the repository**: 
   ```bash
   git clone https://github.com/ekworley/ekworley.github.io
   ```
2. **Navigate into the project directory**: 
   ```bash
   cd ekworley.github.io
   ```
3. **Open the project**: 

   Double-click the `index.html` file to launch it in your preferred web browser, or use a local development server extension in VS Code for live updates.
